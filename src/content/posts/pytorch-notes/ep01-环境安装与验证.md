本文是「PyTorch 学习笔记」系列第 1 篇。

## 安装 Anaconda

```bash
# 创建独立环境，避免污染 base
conda create -n pytorch python=3.11 -y
conda activate pytorch
```

## 安装 PyTorch

根据显卡选择 CUDA 版本，去 [pytorch.org](https://pytorch.org) 复制对应命令。

## 验证 GPU 可用

```python
import torch

print(torch.__version__)
print(torch.cuda.is_available())  # True 即成功
```
